# Coreshift pour Mac

Téléchargements de l'app de bureau [Coreshift](https://coreshift-platform.fr).

**[Télécharger pour Mac](https://coreshift-platform.fr/telecharger/coreshift-mac)** — macOS 13 ou plus, Mac Apple Silicon et Intel.

## Installation

1. Ouvrez le fichier `Coreshift.dmg` téléchargé.
2. Glissez Coreshift dans le dossier Applications.
3. À la première ouverture, macOS demande votre accord : Réglages Système › Confidentialité et sécurité › Ouvrir quand même.

L'app affiche votre espace Coreshift et permet d'enregistrer vos visios (son de l'ordinateur et micro) depuis l'écran
des rendez-vous. Elle vous prévient quand une nouvelle version est disponible.
